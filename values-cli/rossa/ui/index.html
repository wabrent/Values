01 — Elicitation

Nobody can state their values in the abstract.

Ask someone whether they value honesty and they say yes. Ask whether an assistant should call their poem mediocre while they're proud of it, and you learn something real.

Each situation below has two defensible answers. There is no correct one. Pick what you actually want, set how firmly you hold it, and reword anything phrased wrong.

02 — Review

Order matters: when two values collide, the one listed earlier wins. Absolutes are never crossed, defaults yield only to an explicit override, leanings yield freely.

03 — Compile

One file, every runtime.

A values file isn't executable. It compiles down to whatever your model accepts. Compilation is deterministic: the same file always produces byte-identical output, which is what makes the next step attributable.

04 — Proof

A file that claims to steer a model must be measurable.

Every dilemma runs twice against the same model: once bare, once with your compiled file attached. If the file does nothing, the number says so — that is the point of measuring instead of asserting.

Runtime

Local by default. A values file is the last thing that should be sent to someone else's server.
The mock runtime exercises the whole pipeline with nothing installed. It proves the code path, not the model — reports from it are stamped as mock.
